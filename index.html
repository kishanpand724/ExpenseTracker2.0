ℹ️ How to connect your local or cloud PostgreSQL database:
  • Cloud DB (Recommended): Paste your connection string from Supabase, Neon.tech, Aiven, or Railway (e.g. postgresql://postgres.xxx:password@ep-xxx.neon.tech/neondb?sslmode=require).
  • Local DB: Because this web app runs in a secure cloud container, localhost:5432 on your computer isn't directly reachable. Use ngrok (e.g., ngrok tcp 5432) or a free cloud DB on Neon/Supabase to get a public URL!
